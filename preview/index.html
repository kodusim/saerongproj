궁금한 점이 있나요?

데이터가 정리되어 있지 않아도 의뢰할 수 있나요?

네. 파일 형식과 대략적인 양, 해결하고 싶은 문제를 알려주세요. 데이터 상태를 확인한 후 정제 작업을 포함한 진행 범위를 협의합니다.

데이터가 없어도 서비스를 만들 수 있나요?

원하는 서비스에 활용 가능한 공개데이터가 있는지부터 검토할 수 있습니다. 이용 조건과 갱신 가능성을 확인한 후 구현 범위를 정합니다.

비용과 개발 기간은 어떻게 정하나요?

데이터 상태, 필요한 기능, 일정에 따라 달라집니다. 문의 내용을 바탕으로 작업 범위와 산출물을 정한 후 견적과 일정을 협의합니다.

개발 후 운영과 유지보수도 맡길 수 있나요?

배포, 데이터 갱신, 기능 수정 등 필요한 업무를 별도로 협의합니다. 제작 범위와 운영·유지보수 범위를 나눠 안내합니다.
