# 현재 상태와 인계

> **비활성 기록 (2026-09-29):** 데이터 서비스의 다음 작업은 진행하지 않는다. 현재 제품 방향과 인계는 [AI 무당 문서](../ai-shaman/README.md)에 있다. 아래 상태·완료 기록·다음 작업은 방향 변경 전의 이력이다.

업데이트: 2026-09-29 · 현재 단계: 공통 기획 문서 완료, 첫 분야 결정 전.

## 사용자 의도

블링·녹스 같은 데이터 조회/분석 서비스 형태를 참고한다. 한 분야의 데이터를 수집·저장·가공해 가치를 제공한다. 높은 성능의 모델에 설계·인계 문서를 맡긴 뒤 낮은 비용의 모델로 구현을 이어간다. 유튜브를 첫 분야로 확정한 것은 아니다.

## 완료

- P00: 제품 범위, 수집→관측→계산→조회 구조, 데이터 의미/오류/보관 기준, 작업별 완료 조건, 모델 인계 프롬프트 작성.
- 루트 `AGENTS.md` 작성. 상세 설계는 별도 문서로 분리.
- 공식 서비스/YouTube 정책/OpenAI AGENTS.md·모델 안내를 확인하고 `SOURCES.md`에 기록.

## 실제 구현 현황

새 제품의 앱·DB·수집기·API·UI·실데이터 fixture는 없다. 예시 API와 새 제품 파일 경로는 제안이다. 수집 요청, 서버 변경, 새 리소스 생성, 배포, 모델 설정 변경을 수행하지 않았다. 이 단계의 문서 완료는 제품 구현 준비 완료나 수요 검증 완료를 뜻하지 않는다.

## 검증

- 로컬 Markdown 링크 25개가 실제 파일로 연결되는지 확인했다.
- 코드 블록의 닫힘과 JSON 예시 구문을 확인했다. 루트 `AGENTS.md`는 3,785바이트로 짧게 유지했다.
- 작업 의존성, 분야 미정 상태, 제안 경로와 실제 구현의 구분을 검토했다.
- `git diff --check`와 새 문서의 공백 검사를 수행했다. 앱 코드는 변경하지 않아 앱 테스트는 실행하지 않았다.

## 다음 작업

P01은 `needs_input`: 첫 분야와 첫 사용자가 아직 미정이다. 사용자에게 첫 분야를 물었으며 선택을 임의로 가정하지 않았다. 분야가 정해지면 `DOMAIN.md`의 핵심 질문과 첫 출처 카드부터 채운다. 그 다음 P02에서 지표·비용·저장·구현 위치를 고정한다.

I01~R01은 아직 `draft`다. 구현 작업을 미리 실행하거나 현재 운영 앱에 새 기능을 붙이지 않는다. 사용자가 다음 범위를 정하면 상태를 업데이트한다.

## 작업 트리 주의

시작 시 `.claude/settings.local.json`에 기존 수정이 있었다. 사용자 변경이므로 유지했다. 현재 저장소는 saerong 운영 앱이며, 새 제품용 저장소/서버는 아직 정하지 않았다. 과거 세션 문서의 DNS·서버 관련 내용은 현재 사실로 가정하지 않는다.
