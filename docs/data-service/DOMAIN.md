# 첫 분야 명세 — 아직 미정

상태: 작성 전. 아래 빈 항목은 구현 모델이 임의로 채울 기본값이 아니다. 사용자의 답변과 실제 조사 근거를 함께 기록한다. 이 파일은 첫 분야 선정 후에도 계속 유지한다.

## 사용자와 질문

| 항목 | 현재 값 |
|---|---|
| 첫 분야 | 미정 — 유튜브/게임은 예시였음 |
| 첫 사용자 | 미정 |
| 해결할 질문 한 문장 | 미정 |
| 실제 이용 장면/현재 대체 방법 | 미확인 |
| 판단에 필요한 대상 단위 | 미정 |
| 반복 이용 주기 | 미정 |
| 유료 가설 또는 무료 제공 목적 | 미정 |
| 재방문/가치 확인 방법과 기간 | 미정 |
| 실패하면 중단할 조건 | 미정 |

## 첫 출처 카드

출처가 추가되면 이 항목을 출처별로 작성한다. 공식 문서를 읽었다는 사실과 실제 호출이 성공했다는 사실을 구분한다.

| 항목 | 기록할 내용 |
|---|---|
| 출처명/기능/공식 URL | 제공 기관, 데이터 문서, 관련 약관 URL |
| 확인일/근거 | 날짜, 해당 문서/조건; 모르는 것은 미확인 |
| 접근 방식 | 공식 API/다운로드/명시적으로 허용된 웹 수집 |
| 인증/승인 | 필요한 승인과 실제 확보 상태; 키 값은 기록하지 않음 |
| 재사용 조건 | 상업 이용, 공개 표시, 비교·파생 분석, 재배포 각각의 조건 |
| 저장 조건 | 원문/메타데이터/통계/파생값/백업별 보관·갱신·삭제 |
| 식별자 | 이름과 독립된 안정 ID, 변경/병합/삭제 의미 |
| 엔드포인트 | 필요한 최소 호출, 필드, 페이지 방식, 요청당 대상 수 |
| 실제 응답 근거 | 비밀·개인정보 없는 최소 샘플 또는 관찰 기록, 호출 시각 |
| 수치 의미 | 누계/구간/현재값, 단위, 반올림·비공개·결측 표현 |
| 시간 의미 | 원천 기준일/발생일/갱신일, 제공 시간대, 과거 조회 가능 범위 |
| 오류 의미 | 404·빈 결과·권한 실패·쿼터 초과가 각각 의미하는 것 |
| 호출 제한 | 엔드포인트별 쿼터 단위, 일/분 한도, retry 지침 |
| 수집 범위 | 등록 대상 목록/허용된 발견 방식, 초기 대상 상한 |
| 출처 판정 | 사용 가능 / 조건부 / 불가 / 아직 미확인 및 이유 |

API 문서에 필요한 값이 없다고 바로 크롤링을 대체 경로로 확정하지 않는다. 접근·저장·제공이 허용되는지부터 확인한다. 정책이 불명확한 데이터가 핵심이면 출시 가능으로 표시하지 않는다.

## 지표 카드 — 첫 버전 최대 3개를 기본안으로 검토

지표마다 아래를 작성한다. 단순 관측값도 단위·시각·결측 정의가 필요하다.

```text
key / 사용자 표시명:
관측(observed) / 계산(derived) / 추정(estimated):
사용자의 어떤 질문에 답하는가:
입력 출처/필드/대상 단위:
정의/공식/버전:
단위/통화/시간대:
기간과 기준점 허용 오차:
비교 대상 선정/제외 기준:
데이터 부족·분모 0·하락/정정 처리:
출처 변경/의미 변경 처리:
추정치라면 가정·범위·실제값 검증 방법:
보관·공개 가능 조건:
정상 입력과 예상 출력:
경계/오류 입력과 예상 출력:
```

정의가 채워지지 않은 지표는 화면 목업에서조차 사실적인 결과로 제시하지 않는다. 합성 예시라면 예시임을 표시한다.

| 항목 | 현재 값 |

| 구현 저장소/경로/기존 서비스와의 관계 | 미정; 별도 제품 우선 제안 |
| 공개 또는 사용자 승인 데이터 | 미정; 인증 요구도 함께 결정 |
| 초기 대상 수 / 주기 / 보관 일수 | 미정 |
| 갱신 신선도 목표 / 기준점 허용 간격 | 미정 |
| 일일 요청·쿼터 상한 / 재시도 상한 | 미정 |
| 월 서비스 비용 상한 | 미정; 개발 모델 비용과 별도 |
| 계산·수집 피크와 저장량 추정 | 미측정 |
| 배포 환경·도메인 | 미정 |

## 분야 확정 후 구현 진입 기준

핵심 사용자와 질문이 명확하고, 최소 한 출처의 필요한 데이터·권한·저장 조건을 확인해야 한다. 지표와 결측 처리가 예제로 정의되어야 하며, 제한된 수집 비용과 구현 위치가 정해져야 한다. 이 조건이 충족되면 해당 구현 작업을 `ready`로 표시한다.

부차적 이름·색상·부가 기능이 미정이라는 이유로 독립적인 조사나 명세 작성을 멈추지 않는다. 질문은 다음 실제 작업에 필요한 것만 요청한다.
