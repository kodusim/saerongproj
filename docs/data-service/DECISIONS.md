## 변경 방식

기존 결정을 조용히 덮어쓰지 않는다. 바꾸는 ID, 근거, 영향을 받는 명세·작업, 호환성/데이터 이동 필요 여부를 짧게 기록한다. 사용자가 범위 변경을 지시했다면 다시 승인받지 말고 그 지시를 근거로 반영한다.

API 공급자의 정책, 보관 기간, 지표의 의미, 사용자에게 공개할 범위가 바뀌면 관련 `DOMAIN.md`와 데이터 계약을 함께 고친다. 코드에서만 뜻을 바꾸지 않는다.
